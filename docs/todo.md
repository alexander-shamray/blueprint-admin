# Tasks

What is in progress and what remains in `blueprint-admin`, kept as one page
so a reader on GitHub and a session in the tree see the same list. It covers
this repository only: work owed by `blueprint-backend` or
`blueprint-frontend` is raised there and appears here only as the admin-side
task waiting on it.

When and how it is updated is `CLAUDE.md`'s rule (*Working in this repo*).
A row cites its issue or PR by number, and the issue or PR owns the detail.

`README.md`'s *Known limits* are accepted behaviour, not tasks, and are not
repeated here.
